# ⚡ GridWatch Ireland

Energy Planning Intelligence Dashboard for Ireland.

## Features
- 📊 Real-time energy project tracking
- 🔍 Search and filter projects
- 📥 Export data as CSV
- 📈 Project statistics and charts

## Data Source
An Coimisiún Pleanála (pleanala.ie) - Weekly planning lists

## Local Development
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```
